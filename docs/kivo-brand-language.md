# KIVO — Brand Language Specification

Source of truth for product wording. Short by design.

## Core vocabulary (coherent, not interchangeable)

- **KIVO** — the brand. Use sparingly: header lockup, document title, footer.
- **Experience Match** — the product name and descriptor context.
- **Primary tagline:** `Before you try.`
- **Product descriptor:** `Experience Match — find what transfers.`
- **Result language:** `What worked?` / `What differed?` / `Now you know.`
  Used as a set, in that order, only where results are explained.

## Tone of voice

- Plain, specific, calm. Short sentences.
- Name the mechanism, not the magic: "compares", "shows", "counts" — never
  "understands", "knows", "guarantees".
- Honesty markers are part of the voice: fictional, self-reported,
  unverified, local-only. Never soften them for style.
- Banned: revolutionary, unlock, supercharge, seamless, delights used as a
  claim, any claim about emotions, virality, or success.

## Action labels (functional — do not cryptify)

Describe, Clarify with AI, Confirm draft, Edit, Start over, Find relevant
experience, Try again, Add an experience, Save experience, Save changes,
Delete / Yes, delete / Keep it, Show on map, Clear selection, Explore
examples / Hide examples, Copy summary, Continue saved draft, Start fresh.

## Result labels (must stay exact)

- `Your local experience` + `Self-reported` for user stories.
- `Fictional profile` for demo profiles.
- `Fictional case — self-reported, not verified.` for explorer detail.
- Evidence terms: Relevant experience, Reported outcome, What overlaps,
  Important differences and unknowns, Suggested opening question.

## Messages

- Empty: state what is missing and the one next action. No blame.
- Loading: name the real ongoing work
  ("Comparing your approved draft…"). Never fake progress percentages.
- Success: confirm what happened and where it lives
  ("Saved in this browser."). Never over-claim.
- Errors: say what failed, what is unchanged, and the retry action.

## Privacy and AI honesty (always visible when relevant)

- Stories stay in this browser; included only on explicit match.
- Demo profiles are fictional; self-reported is never verified.
- Nothing is sent without an explicit action; consent text precedes
  each AI call, not buried elsewhere.
